# 로컬 문서 업로드

구현일: 2026-08-14

## 지원 형식

- Markdown (`.md`)
- 일반 텍스트 (`.txt`, UTF-8 또는 CP949)
- 텍스트 PDF (`.pdf`)

파일은 최대 5MB, PDF는 최대 100페이지다. 문서는 외부 서버로 전송되지 않고 로컬에서 처리된다.

## 처리 흐름

1. privAI 화면에서 파일을 선택한다.
2. `문서 추가`를 누른다.
3. 파일명과 크기, 확장자를 검증한다.
4. 텍스트를 `wiki/Uploads`의 Markdown으로 변환한다.
5. Wiki를 자동 재색인한다.
6. 같은 화면에서 업로드한 문서에 대해 질문한다.

같은 내용의 문서를 다시 추가하면 SHA-256 기반의 같은 파일을 갱신하므로 중복 문서가 늘어나지 않는다.

## 제한사항

스캔 이미지로만 구성된 PDF에서는 텍스트를 찾을 수 없다. 이 경우 다음 단계에서 로컬 OCR 기능을 사용해야 한다.

## API

- `GET /documents`
- `POST /documents/upload`

업로드 API는 파일 원문을 요청 본문으로 보내고 URL 인코딩된 파일명을 `X-Filename` 헤더로 전달한다.
