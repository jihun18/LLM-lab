# 근거 검증 하니스

구현일: 2026-08-14

## 발견한 오류

사용자가 `평균 속도`를 질문했지만 qwen3:1.7b가 표의 `평균 시간` 열을 선택해 2.814초와 7.205초를 답했다. 검색과 출처 선택은 맞았지만 표의 의미를 잘못 해석한 사례다.

## 검증 방식

1. 질문에서 `속도`, `시간`, `token/s`, `초` 같은 단위를 식별한다.
2. 검색된 Markdown 표의 헤더와 각 행을 구조적으로 파싱한다.
3. 속도 질문은 `token/s` 열, 시간 질문은 `시간` 열과 대응한다.
4. 답변 숫자와 단위가 근거 표와 일치하는지 확인한다.
5. 구조적으로 확정 가능한 표 값은 LLM 생성을 거치지 않고 직접 답한다.

## 기대 효과

- 표 열 혼동 방지
- 숫자와 단위의 환각 방지
- 확정 가능한 질문의 응답속도 향상
- 답변 화면에 `근거 검증 통과` 상태 표시

일반 서술형 답변의 의미 검증은 아직 제한적이다. 향후에는 주장 단위 추출과 별도 검증 루프를 추가한다.
