# PrivAI 모델 모드

## 목적

사용자가 모델 태그만 보고 선택하지 않도록 16GB 실측 결과를 제품 모드로 연결한다.

| 모드 | Ollama 모델 | 5문항 평균 시간 | 평균 생성속도 | 용도 |
|---|---|---:|---:|---|
| 빠른 모드 | qwen3:1.7b | 7.959초 | 13.99 token/s | 기본 데모와 빠른 RAG |
| 균형 모드 | qwen3:4b-instruct | 16.034초 | 6.80 token/s | 속도와 품질 비교 |
| 정밀 모드 | qwen2.5:7b-instruct Q4_K_M | 28.539초 | 3.80 token/s | 시간이 허용되는 작업 |

## 현재 결정

빠른 모드를 기본값으로 유지한다. 정밀 모드는 자동점수가 가장 높았지만 사실성이
완전히 보장되지 않고 응답이 느리므로 사용자가 필요할 때 선택한다. 세 모드 모두
Wiki RAG와 출처·수치 검증 하니스를 동일하게 사용한다.
