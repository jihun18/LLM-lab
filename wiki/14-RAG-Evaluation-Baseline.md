# RAG 평가 기준선

<!-- rag-exclude -->

실행일: 2026-09-23

## 목적

검색 기능을 바꾸기 전에 현재 BM25의 정확도를 고정된 문항으로 측정한다. 이후
한국어 전처리, 의미 검색과 하이브리드 검색을 같은 문항으로 비교한다.

## 평가세트

총 13문항이다.

- 정확한 사실·표 수치·업로드 흐름
- 이유 설명과 요약
- 한국어 조사·의미 표현 변형
- Wiki에 답이 없는 질문

정답에는 허용 출처와 제목, 필수 핵심어·수치, 근거 없음 여부와 최대 응답시간을
기록한다. 같은 사실이 공식 실험 문서와 마일스톤 문서에 모두 있으면 두 출처를
명시적으로 허용한다.

## BM25 검색 기준선

```powershell
python rag_evaluation.py --retrieval-only
```

| 지표 | 결과 |
|---|---:|
| Top-1 정확도 | 53.8% (7/13) |
| Top-3 출처 적중률 | 76.9% (10/13) |

### 실패 유형

- 현재 RAM 질문에서 초기 8GB 실험 문서가 최신 16GB 기준선보다 먼저 검색됨
- 검색 방식 질문에서 구현 설명보다 오류 사례가 먼저 검색됨
- 검증 상태 질문에서 사용법 문서가 먼저 검색됨
- 업로드 처리 흐름 질문에서 정답 문서가 Top-3에 포함되지 않음
- 근거가 없는 두 질문도 `PrivAI`, `Wiki` 같은 공통어 때문에 결과가 남음

## 해석

현재 BM25는 정확한 모델명과 제목 단어가 포함된 질문에는 강하지만 최신성,
문서 중복과 근거 없음 판정에는 약하다. 다음 개선은 평가 문항을 바꾸지 않고
최신 문서 가중치, 불용어·최소 일치 조건을 먼저 시험한 뒤 의미 검색과 비교한다.

## 1차 검색 개선 결과

평가세트는 그대로 유지하고 다음을 변경했다.

- 공식 기준 문서에 설명 가능한 `rag-priority` 가중치 부여
- 하위 제목 조각에도 문서 최상위 제목을 검색 토큰으로 포함
- `업로드하면`, `사용해`, `처리돼` 같은 동사형의 원형 토큰 추가
- 긴 질문에서 의미 있는 토큰이 두 개 미만으로 일치하면 근거 없음 처리
- 평가 보고서 자체는 검색 색인에서 제외해 정답 유출 방지

| 지표 | 개선 전 | 개선 후 |
|---|---:|---:|
| Top-1 정확도 | 53.8% (7/13) | 92.3% (12/13) |
| Top-3 출처 적중률 | 76.9% (10/13) | 100% (13/13) |

처음 실패했던 현재 RAM 질문을 1.7B 전체 RAG로 다시 실행한 결과 검색 점수와
답변 점수가 모두 100점이었고, 16GB·i3-7100·올바른 출처를 포함했다. 응답시간은
22.46초였다.

남은 Top-1 실패 1건은 검증 상태 질문에서 과거 근거 검증 문서가 1위, 더 구체적인
현재 화면 상태 문서가 2위로 나온 사례다. 100%에 맞추기 위한 과도한 가중치 조정보다
의미 검색 비교용 실패 사례로 보존한다.

## 1.7B 전체 답변 평가

13문항 전체 실행의 최초 결과는 다음과 같다.

| 지표 | 결과 |
|---|---:|
| Top-1 정확도 | 92.3% |
| Top-3 출처 적중률 | 100% |
| 평균 답변 점수 | 89.4점 |
| 평균 응답시간 | 23.265초 |
| 시간 기준 통과율 | 100% |

낮은 답변은 모델이 정답 뒤에 근거 없음 문장을 덧붙이거나 절차 핵심어를 생략한
사례였다. 유효 본문 뒤의 잘못된 거절 문장을 제거하고, 답변과 가장 많이 겹치는
검색 근거를 자동 선택하며, 절차·수치 비교 지시를 강화했다.

| 표적 재시험 문항 | 개선 전 | 개선 후 |
|---|---:|---:|
| 검증 상태 구분 | 50.0 | 100.0 |
| 업로드 처리 흐름 | 50.0 | 91.7 |
| `까닭` 표현 변형 | 25.0 | 100.0 |

실패 문항만 재실행할 때는 `--case-ids`를 사용한다.

## 개선 후 최종 1.7B 기준점

동일한 13문항을 다시 전체 실행한 최종 결과다.

| 지표 | 최초 | 개선 후 |
|---|---:|---:|
| Top-1 정확도 | 92.3% | 92.3% |
| Top-3 출처 적중률 | 100% | 100% |
| 평균 답변 점수 | 89.4점 | 99.4점 |
| 평균 응답시간 | 23.265초 | 20.293초 |
| 시간 기준 통과율 | 100% | 100% |

13문항 중 12문항은 답변 100점이었다. 업로드 처리 흐름만 91.7점으로, 실제 6단계와
Markdown·재색인은 정확했지만 SHA-256 해시라는 보조 핵심어를 생략했다. 검색과
출처는 정확하므로 이 결과를 현재 PrivAI 1.7B 공식 기준점으로 사용한다.

## 전체 RAG 평가

검색뿐 아니라 답변·출처·수치·거절·응답시간을 평가하려면 다음을 실행한다.

```powershell
python rag_evaluation.py --models qwen3:1.7b
python rag_evaluation.py --models qwen3:1.7b qwen3:4b-instruct qwen2.5:7b-instruct
```

결과는 `benchmark-results`에 JSON·CSV·Markdown으로 저장되며 Git에는 포함하지 않는다.
