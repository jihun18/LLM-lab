## 현재 역할 구분

- `qwen3:0.6b`: 기능 개발, 연결 확인, 빠른 반복 테스트
- `qwen3:1.7b`: 사용자 데모와 한국어 품질 평가

## 평가 원칙

모델마다 동일한 문항과 설정을 사용한다. 속도 외에 다음 항목을 기록한다.

1. 형식 지시 준수
2. 한국어 자연스러움
3. 사실성
4. 근거 없는 내용 생성 여부
5. 모델 적재 후 평균 token/s

`benchmark.py`의 자동점수는 형식, 한국어 비율과 핵심어만 확인한다. 사실성과 자연스러움은 생성된 Markdown 보고서에 사람이 1~5점으로 기록한다.
