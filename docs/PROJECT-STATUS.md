## 완료된 사용자 흐름

```text
Ollama 모델 준비
→ FastAPI 실행
→ MD·TXT·PDF 문서 선택
→ 로컬 Markdown 변환
→ Wiki 자동 재색인
→ 질문
→ BM25 근거 검색
→ 모델 답변 또는 결정론적 표 답변
→ 출처 표시
→ 표·금액·날짜·단위 검증 상태 표시
```

## 실제 기준 성능

| 모델 | 평균 시간 | 평균 생성속도 | 용도 |
|---|---:|---:|---|
| qwen3:1.7b | 7.959초 | 13.99 token/s | 기본 데모·빠른 RAG |
| qwen3:4b-instruct | 16.034초 | 6.80 token/s | 균형 모드 후보 |
| qwen2.5:7b-instruct Q4_K_M | 28.539초 | 3.80 token/s | 정밀 모드 후보 |

위 값은 RAM 16GB에서 측정한 5문항 평균이다. 7B는 실행 가능하지만 기본 모델로
쓰기에는 느리며, 자동점수 우위가 곧 사실성 우위를 뜻하지 않는다.

## 현재 검증 상태 의미

| UI 상태 | 보장 범위 |
|---|---|
| 표 수치 검증 통과 | 질문 단위와 표 열·값 일치 |
| 금액·날짜·단위 검증 통과 | 해당 문자열이 근거 원문에 존재 |
| 수치 근거 검증 통과 | 시간·속도·용량 등 수치 문자열이 근거 원문에 존재 |
| 검증 실패 | 구조화 값 일부가 근거에 없음 |
| 사람 검토 필요 | 출처는 있으나 의미 전체는 자동 검증하지 않음 |

## 알려진 기술 부채

- RAG 검증을 위해 전체 답변 생성 후 표시하므로 진정한 토큰 스트리밍과 충돌
- BM25 메모리 인덱스는 문서가 매우 많아지면 확장성 제한
- Markdown 표 파서는 병합 셀과 복잡한 표를 지원하지 않음
- 구조화 주장 검증은 단위 변환이나 의미적 동치까지 처리하지 않음
- PDF는 텍스트 추출만 지원하고 OCR·격리 미지원
- 인증과 사용자 구분 없음
- 일반 서술문의 의미적 사실성은 출처 연결 후에도 사람 검토가 필요
