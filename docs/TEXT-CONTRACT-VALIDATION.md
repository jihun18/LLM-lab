# 역할 연결·필수 문구 검증 보강

작업일: 2026-10-06. 기본 모델 1.7B와 전체 근거 모드는 유지한다.

## 검사 범위

- 역할 질문: 원문의 `- 역할: **대상**` 쌍을 추출한다. 질문에 등장한 대상이 두 개 이상일 때만 적용한다. 답변의 대상 뒤 구절에 다른 대상 역할의 고유한 원문 단어가 두 개 이상 나타나면 불일치로 표시한다.
- 문구 목록: 질문에 개수와 `문구`가 명시되고 원문의 백틱 불릿 목록 개수가 일치할 때 누락·변형을 검사한다. 아이콘·공백·구두점 차이는 무시하되 문구 글자는 유지해야 한다.
- 기존 수치 검증 실패는 보존한다. 출처 차단은 기존 서비스 검증이 먼저 처리한다.
- 프롬프트에 역할 연결 유지와 목록 완전성 우선 지시를 추가했다.

오류가 없어도 의미 전체가 맞다고 판정하지 않는다. 화면에는 `역할·목록 제한 검사 완료 · 문장 의미는 사람 검토 필요`로 표시한다. 오류를 찾으면 서비스의 기존 검증 실패 처리로 전달한다.
