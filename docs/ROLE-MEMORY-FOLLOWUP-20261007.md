## 다음 개선 우선순위

1. 역할·메모리 질문의 `RSS`, `RAM`, `및`, `맡는 일` 표현을 공통 요구 분석과 부분 원문 추출에 연결한다. 메모리 근거가 없다고 이미 확인 가능한 역할까지 버리지 않아야 한다.
2. 역순 역할 목록 충돌은 위 공통 차단과 분리된 사례로 평가한다. 자유 서술의 의미를 자동으로 같거나 다르다고 단정하지 않는다.
3. 쉼표 숫자 형식 지원 여부는 별도 결정한다. 현재 안전한 보류를 완전한 추출 성공으로 집계하지 않는다.
