# 역할 비교표의 제한적 원문 추출

작업일: 2026-10-06

## 목적

출처 번호를 정확하게 선택해도 모델은 `Flask는 간단한 기능만 구현할 수 있다`처럼
원문에 없는 설명을 덧붙일 수 있었다. 역할과 차이를 묻는 좁은 질문에서는 검색된
Markdown 비교표의 셀을 직접 복사해 이 생성 오류를 피한다.

## 적용 범위

- 질문에 역할 또는 용도와 차이 또는 비교 표현이 함께 있어야 한다.
- 검색된 표는 첫 열이 `항목`이고, 질문에 명시된 두 개 이상의 대상 열이 있어야 한다.
- `역할` 행은 필수다. 있으면 `API 문서` 행도 함께 복사한다.
- 대상 이름과 제한된 질문 표현 이외의 요구가 있으면 기존 생성 경로로 넘긴다.
- 누락 셀·중복 행·비교표 간 값 충돌이 있으면 직접 추출하지 않는다.

예: `FastAPI와 Flask의 역할과 차이를 설명해줘.`는 역할과 API 문서 셀을 복사한다.
성능·속도·선택 이유·사용 포트·예시까지 요구하거나 알 수 없는 대상을 추가한 질문은
이 경로로 일부만 답하지 않는다. 기존 생성 및 검증 경로가 처리한다.

결과에는 프로젝트 구현 비교이지 프레임워크의 일반적인 성능이나 기능 한계를
뜻하지 않는다는 안내와 실제 비교표 출처를 붙인다. 검색 1위가 아닌 전달 근거의
비교표를 사용했을 때도 그 표의 출처만 표시한다.

## 실행과 검증

공유 RAG 서비스에서 모델 호출 전에 수행한다. 모델 식별자는
`deterministic-comparison`, 실행 경로는 `deterministic_role_comparison`이다.
모델 생성 속도 비교에서는 이 경로를 생성 결과와 구분한다. 생성만 비교하는 실험에서
원문 추출을 끄는 설정도 유지한다.

14개 테스트를 추가했고 전체 134개 테스트가 통과했다. 임의 대상의 표 복사,
추가 요구 거절, 누락·충돌 처리, 실제 Wiki를 검색한 두 질문의 모델 호출 없음,
추출을 끈 경우의 생성 경로를 확인했다. 이는 개발 회귀 확인이며 독립 평가 정확도나
브라우저 실측 성능을 의미하지 않는다.

화면의 `역할 비교표 원문 추출 완료`는 선택된 셀을 복사했다는 의미다.
문서 자체의 사실성이나 모든 서술 의미를 검증했다는 의미는 아니다.
복합 이유 설명의 품질과 비교표 이외 문서의 의미 충돌은 여전히 별도 검토 과제다.
