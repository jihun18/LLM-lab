# 역할 표현과 대상 수에 독립적인 메모리 보호

작업일: 2026-10-07.

## 변경

- 메모리·RAM·RSS 요구를 역할 분석과 별도로 확인한다.
- 다중 역할 질문의 제한 문법으로 처리하지 못하면 공통 메모리 보호 경로로 들어간다.
- 근거가 없거나 측정 값이 충돌하면 모델을 호출하지 않고 부족 항목을 안내한다.
- 지원하는 측정 행이 있으면 조건·출처와 함께 복사하지만, 임의 문장의 다른 요구까지
  해결했다고 표시하지 않는다. 해당 경로는 부분 답변 또는 생성 차단 상태다.
- 고정 근거 비교에서 텍스트 추출을 끄더라도 이 안전 경로는 유지한다.
- ‘맡는 작업/맡는 일’ 역할 의역을 제한적으로 추가하고, 메모리가 포함된 단일 대상
  역할 질문도 기존 원문 부분 답변 경로로 처리한다.
- 생성 답변에서 수치 일치만 확인한 경우 `review_required` 상태와
  ‘수치 근거만 확인 · 질문 전체 의미는 사람 검토 필요’ 문구를 표시한다.
  숫자 검사 자체의 `passed`와 원래 검사 내용은 `numeric_verification`에 유지한다.

## 검증

새 평가 n04·n05를 개발 회귀 사례로 전환했다. 운영 코드를 고친 뒤 같은 문항을
재실행해 모델 없이 두 역할/단일 역할과 대상별 메모리 근거 부족을 제시하는
`partial` 상태를 확인했다.

결과: `benchmark-results/edge-holdout-20261007-162035.json`.
최초 결과와 고정 문항 기준은 수정하지 않았다. 이번 재실행은 독립 평가가 아니다.
`tests/test_memory_guard.py`는 대상 수·미지원 의역·빈 검색·스트리밍·고정 근거 호출,
측정 행 조건 보존 및 다른 요구 미확인 표시, RAM/RSS 대상명 오인 방지,
수치 일치와 전체 생성 의미 검토 구분을 검사한다.
추가 회귀 검사 14개 및 평가 도구 구조 검사 3개를 포함해 전체 테스트 199개가 통과했다.
실행 중인 웹 서버는 이번 작업에서 재시작하지 않았다.

## 제한

메모리 언급을 보수적으로 처리하므로 개념 설명 질문도 측정 근거 부족으로 제한될 수 있다.
일반 의미 분석이나 모든 자원 요구의 완전성 검사가 아니다. 한글 대상명은 아직
측정 행 매칭 대상이 아니며, 알 수 없는 대상 형식이라고 안내한다.
도구 열 위치·KiB 표 지원 및 비교표와 서술 목록의 의미 충돌은 이번에 수정하지 않았다.
Wiki 측정 데이터를 추가하지 않았으며 실제 응답시간·메모리 비교는 여전히 미해결이다.
