# 프로젝트 개요

## 한 문장 정의

privAI는 저사양 Windows PC에서 실행되는 경량 LLM에 로컬 문서 검색과 근거 검증을 결합한 개인정보 보호형 AI 실험 플랫폼이다.

## 문제 정의

클라우드 LLM은 사용하기 편하지만 개인 문서와 민감 데이터를 외부 서비스에 전송할 수 있고, 비용·네트워크·서비스 정책에 의존한다. 반대로 로컬 경량 모델은 개인정보와 오프라인 사용 측면에서 유리하지만 지식량과 사실성이 제한적이다.

privAI는 다음 조합으로 이 간극을 줄인다.

1. Ollama로 경량 모델을 PC에서 실행한다.
2. Obsidian Markdown과 사용자가 추가한 문서를 로컬에서 검색한다.
3. 답변과 함께 실제 검색 근거를 표시한다.
4. 표, 날짜, 금액과 단위 수치는 코드 기반 하니스로 재검증한다.
5. 모델·검색·검증 성능을 반복 가능한 평가 문항으로 측정한다.

## 주요 사용자 시나리오

### 개인 문서 도우미

사용자가 Markdown, TXT 또는 PDF를 추가하고 자연어로 질문한다. 시스템은 관련 문서를 찾아 답변과 출처를 보여준다.

### 공공데이터·행정 안내 데모

지원 정책, 지역 복지, 안전 매뉴얼 같은 공개 문서를 주제별 데이터 팩으로 교체해 공모전용 서비스로 전환한다.

### 경량 모델 연구

같은 하드웨어와 질문으로 모델 크기, 속도, 한국어 품질, 지시 준수와 사실성을 비교한다.

## 공모전 확장 전략

공통 엔진은 유지하고 다음 요소만 교체한다.

- `wiki/`와 공개 데이터
- 시스템 프롬프트
- 화면 제목과 설명
- 평가 질문 세트
- 발표용 문제 정의와 사용자 시나리오

후보 주제는 공공 행정문서, 지역 복지정보, 소상공인 지원, 재난·안전 매뉴얼과 개인 지식관리다.
