# 수정 후 1.7B·4B·양자화 7B 비교

실행일: 2026-10-06. RAM 16GB, i3-7100 CPU 추론 환경에서 모델을 순차 실행한다.
현재 서비스의 연도·모델 태그 조건 검증을 세 모델에 모두 동일하게 적용했다.
이번 기록은 기존 수정 전 1.7B·4B 결과와 섞지 않는다.

## 실험 조건

- 생성 모델: qwen3:1.7b, qwen3:4b-instruct, qwen2.5:7b-instruct.
- 설치된 7B의 로컬 `/api/show` 확인: GGUF, 7.6B 파라미터, Q4_K_M.
- 같은 하이브리드 검색·EmbeddingGemma·하한0.4395475를 사용하고 검색 결과를 먼저 고정한다.
- 같은 시스템 지시, 컨텍스트2048, 최대 생성256, temperature0.3, seed42.
- Qwen3 일반 태그에는 기존 공용 클라이언트의 비사고 지시를 유지한다. Instruct는 원문 지시다.
- 대상 생성 모델을 메모리에서 내린 상태를 확인하고 모드 태그 질문으로 콜드 응답을 측정한다.
- 콜드 답변은 웜런 점수에서 제외한다. 같은 질문을 포함한 7문항을 곧바로 순차 실행한다.
- 실제 생성4개: 모드 태그·프레임워크 역할·검증 상태·중복 업로드.
- 서비스 거절2개: 다른 연도의 정책·미시험 모델. 표 추출1개: 과거 모델 속도 표.

검색 준비 및 최초 임베딩 시간은 답변 시간에 포함하지 않는다. 표 추출·거절0초는
실제 0초를 보장한다는 뜻이 아니라 이 평가 도구가 생성 경로를 호출하지 않아 기록한
값이다. 실제 앱 API 왕복·검색 시간은 별도 측정해야 한다.

전체7문항 자동 평균은 1.7B100.0, 4B100.0, 7B99.1이었다. 모두 같은 서비스가
수행하는 거절2개와 표 추출1개가 포함되므로 모델 생성 품질의 대표 점수로 사용하지 않는다.
같은 질문 순서·근거·한도로 한 번만 실행했으며 다른 결과와 섞지 않았다.

생성11.015초였다. 콜드 전체가 모델 적재 시간만은 아니다. 약998개 입력 토큰의
근거 처리 비용이 컸다. 같은 질문의 7B 웜런은11.432초이고 입력 처리는0.238초라
프롬프트 캐시 효과를 확인했다. 다른 세 질문의 입력 처리는 약29~34초였다.

## 답변 원문 대조 — AI 관찰

사람 평가 완료가 아니다. Wiki의 모델 모드 표, 프레임워크 결론, 검증 상태 목록,
업로드 처리 흐름을 저장된 답변과 직접 대조했다.

| 문항 | 1.7B | 4B | 양자화 7B |
|---|---|---|---|
| 두 모드의 모델 태그 | 두 태그 정확·출처 표기 중복 | 두 태그 정확 | 두 태그 정확 |
| 프레임워크 역할 | 세 역할 정확·설명 반복·출처3개 | 세 역할 정확·간결한 목록 | 세 역할 정확·간결한 문장 |
| 검증 상태 네 가지 | 4개 모두 제시 | 4개 모두 제시 | 3개만 제시·사람 의미 검토 상태 누락 |
| 중복 업로드 | SHA-256와 동일 내용 갱신 설명 | 원문 조건 정확 | 해시 기준 설명·문장 표현이 다소 어색함 |

7B의 검증 상태 문항 자동점수는93.8이지만 네 번째 상태를 빠뜨렸으므로 내용은
부분적이다. 높은 자동점수가 완전한 답변이라는 뜻이 아니다. 세 모델 모두 문서에
없는 연도·모델 질문은 생성 전 서비스가 거절했고 과거 속도 표도 공통 추출기로 답했다.
이 성공을 7B의 더 좋은 거절 능력이라고 해석하면 안 된다.

결정: 기본1.7B 유지, 4B는 간결한 답변의 비교 후보, 7B는 선택형 실험 모델로 유지한다.
이 표본에서 7B는 안정적으로 실행됐지만 속도·품질상 기본값으로 바꿀 근거는 없었다.
다음은 모델 확대보다 제공하는 근거 길이를 줄이되 필요한 정보와 출처를 보존하는
별도 실험이다. 사람 확인과 반복 웜런 평가 후 결정해야 한다.

## 결과 해석의 한계

모델 성능 시간은 실제 생성4문항만 평균낸다. 전체7문항 평균에 빠른 거절·표 추출을
넣어 모델이 빨라진 것으로 발표하지 않는다. 저장된 Ollama load/prompt/eval 시간과
생성 토큰 수를 함께 확인한다. 첫 웜 문항은 콜드 측정과 같은 프롬프트라 프롬프트
캐시의 영향을 받을 수 있다. 콜드란 모델 적재 상태가 비어 있다는 뜻이며 OS 디스크
캐시까지 비운 완전한 콜드 부팅 실험은 아니다.

자동 점수는 핵심어·값·출처·검증 상태의 점수다. 역할 배정, 질문 조건 일치와 사실성은
원문 대조가 필요하다. 한 번 실행한 내부 진단 세트이므로 모델 일반 성능·통계적
우수성을 결론내리지 않는다. seed를 같게 해도 모델이 다르면 출력이 같다는 뜻은 아니다.
