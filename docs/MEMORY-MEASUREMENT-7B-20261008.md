## 7B RSS 요약

단위 MiB. 요청 평균은 각 요청 구간 길이로 가중한 표본 기반 평균이다. 요청 사이 유휴는 제외하고 시작/끝 경계 표본은 포함한다.

| 범위 | 유휴 평균 | 요청 표본 최소 | 요청 시간 가중 평균 | 요청 표본 최대 |
|---|---:|---:|---:|---:|
| FastAPI 서버 트리 | 54.07 | 54.13 | 55.69 | 57.25 |
| Ollama 서비스 본체 | 71.00 | 49.95 | 70.09 | 73.86 |
| 모델 runner 트리 | 4,654.34 | 4,654.34 | 4,672.07 | 4,682.58 |

runner 트리는 자식 콘솔 호스트를 포함한다. 서비스 직속 검증된 시스템 콘솔 호스트는 별도 제외 목록에 기록한다. RSS 합계는 공유 페이지가 중복될 수 있고 전체 설치 구성 또는 전체 PC의 고유 물리 메모리/필요 RAM과 같지 않다. warm 요청이며 cold start 최고 메모리도 아니다.

연속 표본의 평균 간격 계산에는 경계 표본을 포함하고 요청 사이 유휴는 제외한다. 시간 가중 평균은 표본 사이 값이 유지된다고 가정한 값이므로 긴 공백 중 실제 RSS 변화를 복원하지 못한다. 따라서 **순간 최대 메모리의 정밀 비교는 보류**한다. 특히 최대 약 1.07초 공백을 100ms 충족으로 표현하지 않는다.

## 세 모델의 관찰값

동일 스케줄러 방식의 [1.7B 재측정](MEMORY-MEASUREMENT-20261008.md)·[4B 측정](MEMORY-MEASUREMENT-4B-20261008.md)·7B 측정을 나란히 기록한다. 1.7B 첫 상대 대기 스케줄러 실험은 이 표에 섞지 않는다.

| 정확한 모델 이름 | runner 평균 RSS(MiB) | runner 표본 최대(MiB) | 평균 간격(ms) | 최대 간격(ms) | 목표 누락 |
|---|---:|---:|---:|---:|---:|
| qwen3:1.7b | 1,397.76 | 1,401.04 | 101.69 | 202.78 | 4 |
| qwen3:4b-instruct | 2,779.23 | 2,796.82 | 110.36 | 408.01 | 34 |
| qwen2.5:7b-instruct | 4,672.07 | 4,682.58 | 145.97 | 1,072.33 | 222 |

これは 서로 다른 실행의 관찰 RSS다. 7B는 Qwen2.5, 1.7B·4B는 Qwen3이고 instruct/접미사 차이도 있다. 실행 커밋·모델 digest·생성 길이·외부 상태가 모두 동일하지 않으며 코드 지문은 각 보고서에 별도 보존됐다. 모델 크기 하나만의 영향, 프레임워크 메모리 우열, 추론 속도 우열 또는 메모리 최적화 효과를 입증한 비교가 아니다.

다음 개선 후보는 수집기 자체 읽기 비용과 OS 대기 지연을 분리해 분석하는 것이다. 안전 검사 빈도를 임의로 줄이거나 시간 가중 평균을 실제 연속 메모리 평균이라고 재해석하지 않는다. 추가 진단 전에는 표본 누락의 원인을 확정하지 않는다.
