# 항목별 추가 검색과 부분 원문 답변

작업일: 2026-10-06

보호 기능을 커밋한 뒤의 후속 개선이다. 사용자 4B 화면에서 단순 비교는 정상,
세 복합 질문은 부족 항목 안내로 안전하게 보류되는 것을 확인했다.
이제 검색에서 놓친 근거를 제한적으로 찾아 답변 가능한 항목을 늘린다.

## 범위

역할·용도와 영문 도구명이 명시된 프로젝트 질문 중, 제한된 질문 표현으로
역할·차이·생성속도·함께 쓰는 이유를 요구한 경우만 처리한다.
포트·메모리·예시·연도 등 처리하지 않는 추가 요구를 무시한 채 일부만 복사하지 않는다.
그런 질문은 기존 생성·보호 경로로 넘긴다. 범용 질문 분해 기능은 아니다.

## 처리

- 현재 검색 결과의 부족한 항목을 대상으로 최대 4개 질의를 만든다.
- 각 질의에서 3개 결과만 요청하며, 중복을 제외해 최대 6개 조각을 추가한다.
- 사용자가 선택한 검색 모드와 기존 결과를 유지한다. 전체 Wiki를 직접 훑거나 웹 검색하지 않는다.
- 역할은 비교표의 셀을 복사한다. 속도는 대상 이름이 정확히 일치하는 실측 표의 행 전체를
  복사해 모델·시간 등 조건을 유지한다. 같은 대상에 서로 다른 행 값이 있으면 충돌로 안내한다.
- 함께 쓰는 이유는 모든 요청 대상과 제한된 이유 표현이 한 문장에 있는 원문만 복사한다.
  역할 분담을 시스템이 임의로 만들어내거나 실제 API 연결을 추측하지 않는다.
- 각 복사 항목에 해당 출처를 붙이며, 표시 근거는 사용한 절만 포함한다.
- 확인한 항목이 있으면 원문 답변과 미확인 목록을 분리한다. 미확인 항목이 남으면
  질문 전체가 해결되지 않았다고 명시한다. 부분 답변을 자동 검증 성공으로 표시하지 않는다.

`deterministic_requirement_copy`는 모델 호출 없는 경로다. 요청 모델은 별도로 기록한다.
미확인 항목이 있으면 `answer_status=partial`, 전부 복사하면 `source_copied`다.
원문 복사 완료는 문서 자체의 사실성이나 이유 문장의 의미 정확성을 보장하지 않는다.
고정 근거 모델 비교는 `grounded_response`를 직접 호출하므로 추가 검색이 끼어들지 않는다.

## 개발 회귀 확인

13개 테스트를 추가해 전체 159개가 통과했다. 실제 Wiki BM25에서 속도 복합 질문은
`02-Framework-Comparison.md#사용자 실측 결과`를 보충해 11.75/12.61 token/s 행을 찾았다.
이 값은 과거 한 질문의 모델 생성 기록이며 프레임워크 자체 성능이나 공정한 우열 비교가 아니다.
Django와 함께 쓰는 이유 질문은 역할만 복사하고 미확인 항목을 남겼다.
임의 도구 표로 검색 모드 유지·중복 제거·원문 충돌·추가 요구 제외·부분 스트리밍을 확인했다.
이 질문들은 개선에 사용한 회귀 질문이며 독립 평가 정확도로 세지 않는다.

## 남은 한계

보충 검색은 의역·한글 도구명·문장 여러 개에 나뉜 근거를 충분히 처리하지 못할 수 있다.
원문 이유 표현 검사는 의미 검증이 아니다. 역사적 표 조건을 복사하지만 모든 실행 조건을
재현하는 것은 아니다. 후속 과제는 별도 평가 질문과 복합 근거 충돌·시간 조건의 더 엄격한 검사다.

## 실제 화면 확인

재시작 후 빠른 모드·BM25에서 세 질문을 실행했다. 속도 질문은 모델·전체 시간·생성속도
행과 주의 문구를 표시했고, Django와 이유 질문은 역할만 복사하며 미확인 항목을 명시했다.
사용한 절만 근거로 표시됐다. 세 스트리밍 요청은 HTTP 200, 브라우저 콘솔 오류는 없었다.
모델 호출 없는 경로의 확인이며 4B·7B 생성 성능 재평가를 뜻하지 않는다.

## 사용자 후속 화면 확인

추가 검색 개선 후 사용자가 세 질문의 결과를 네 장의 화면으로 제공했다.
화면에 선택 모델과 검색 모드는 포함되지 않아 이 확인에서 별도로 확정하지 않는다.

- Django 추가: FastAPI·Flask 역할과 각 출처를 표시했고, Django는 검색 근거 부족으로
  분리했다. `일부 항목 원문 추출 · 미확인 항목 있음` 상태가 표시됐다.
- 속도 추가: FastAPI 13.975초·11.75 token/s, Flask 5.003초·12.61 token/s와
  당시 모델 qwen3:1.7b 및 실측 결과 절의 출처가 표시됐다. 프레임워크 자체 성능이나
  동일 조건의 우열이 아니라는 주의와 `요청 항목 원문 추출 완료` 상태도 확인했다.
- 함께 쓰는 이유: FastAPI·Streamlit 역할은 표시하고, 이유의 원문은 검색 근거 부족으로
  분리했다. 질문 전체가 해결되지 않았다는 안내와 부분 추출 상태를 확인했다.

세 개발 회귀 질문에서 기대한 원문 답변·부분 답변이 표시된 확인이다. 이를 모델 생성
정확도 향상, 독립 평가 성공률 또는 범용 복합 질문 처리 완료로 해석하지 않는다.
