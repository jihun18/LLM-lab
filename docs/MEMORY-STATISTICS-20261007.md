# 최대·평균·최소 메모리 요구 구분 — 2026-10-07

## 변경한 동작

‘FastAPI와 Flask의 역할과 최대 메모리 사용량도 비교해줘.’ 질문은 이제 확인 가능한 역할을 복사하고, 별도로 다음을 안내한다.

- FastAPI의 대상별 최대 메모리 사용량 (검색 근거 부족)
- Flask의 대상별 최대 메모리 사용량 (검색 근거 부족)

최대·평균·최소는 각각 독립적인 요구다. ‘최대·평균·최소 메모리 사용량’처럼 함께 물으면 각각 확인한다. 추가 검색어에도 조건을 유지하며, 검색 최대 4회·각 3개 결과·새 근거 최대 6개 제한은 변경하지 않았다. ‘비교해줘/비교해주세요’ 표현도 부분 답변 경로에 연결했다.

## 근거 인정과 안전 제한

- 메모리/RSS/RAM 앞뒤에 붙은 한국어 최대·평균·최소만 제한적으로 인식한다. 평균 생성속도를 평균 메모리로 해석하지 않는다. 인식되지 않은 조건은 완전 답변 경로에서 제외한다.
- 명시적 도구명 열과 유효한 수치·단위를 가진 표에서, 해당 통계의 명시적 열만 사용한다. 예: ‘최대 RSS’, ‘평균 RSS’, ‘최소 RSS’, ‘최대 메모리 사용량’. 통계명과 지원 지표명의 앞뒤 조합을 제한적으로 지원한다.
- 일반 ‘RSS’ 열이나 문서 제목 ‘최대 메모리’만으로는 최대 측정을 인정하지 않는다. ‘최대 허용 메모리 사용량’ 같은 용량/허용 한계 표현도 측정 통계로 추측하지 않는다.
- 일반 측정값을 최대/평균/최소로 바꾸어 부르지 않는다. 여러 행의 최대·최소나 평균을 계산하지 않는다.
- 요청한 통계의 열이 중복되어 모호하면 사용하지 않는다. 모델·입력 등 조건은 유지하고 다른 메모리 지표 열은 요청한 통계의 출력에서 제외한다. 조건이 다른 행은 수치가 같아도 임의 선택하지 않는다.
- 역할 근거는 유지하며, 메모리 통계 근거가 없거나 충돌하면 조건별 미확인 항목으로 안내한다. 고정 문맥 호출이나 추출 비활성화에서도 공통 메모리 보호가 같은 조건을 보존한다.
- 일반 자연어 의미 추론은 하지 않는다. 문장에 잡힌 통계는 요청 대상 전체에 공통 적용한다. ‘A는 최대, B는 평균’ 같은 대상별 조건 배분, 표의 통계명 열을 별도 행으로 쓰는 구조, 제목으로만 통계가 지정된 표는 지원 범위에 포함하지 않는다. 단위 변환과 같은 조건 성능 우열 판단도 하지 않는다.
