# 새 표현의 탐색적 범위 확인

운영 코드 기준: `15fb7bc`. 개선에 사용하지 않은 아래 표현을 먼저 정하고,
실제 Wiki·BM25·top-k 3에서 자동 경로만 확인한다. 필요한 모델 생성은 보류하며,
보류를 정답이나 실패로 임의 분류하지 않는다. 이번 확인 중 운영 코드를 수정하지 않는다.

| 질문 | 실행 전 확인 기준 |
|---|---|
| FastAPI와 Streamlit은 어떤 일을 하며 응답속도는 어때? | 두 역할·실측 생성 행·정확한 출처, 전체 응답속도 근거 부족 명시 |
| Flask와 FastAPI의 용도와 생성 속도도 알려주세요. | 두 역할·실측 생성 행·정확한 출처와 일반 성능 비교 아님 안내 |
| Flask와 Streamlit의 업무와 응답 속도는 어때? | 업무 요구가 누락되지 않고 응답속도와 생성속도 구분; 모델 경로면 보류 |
| Flask와 Streamlit은 어떤 일을 하며 메모리 사용량도 알려줘. | 메모리 요구를 버린 일부 원문 추출은 불가; 모델 경로면 보류 |

소수 탐색 질문이며 통계적인 독립 평가 정확도나 모든 의역을 처리한다는 증거가 아니다.

## 실행 결과

- 첫 질문: `deterministic_requirement_copy`, `partial`. 두 역할과 당시 생성 행의
  출처를 표시하고 전체 응답속도의 동일 조건 비교 근거 부족을 명시했다. 기준 충족.
- 둘째 질문: 같은 원문 복사 경로, `source_copied`. 두 역할과 당시 모델·시간·생성속도
  행 및 프레임워크 자체 성능 비교 아님 안내를 표시했다. 기준 충족.
- 셋째 질문: 실제 모델 생성이 필요해 보류. `업무`는 현재 자동 역할 의역 인식 범위 밖이다.
  최종 답변의 정확성이나 안전성을 이번 확인으로 확정하지 않는다.
- 넷째 질문: 실제 모델 생성이 필요해 보류. 메모리 요구를 자동 원문 추출로 누락시키지
  않았다는 경로 확인만 가능하다. 메모리 답변 자체는 검증하지 않았다.

자동 처리 기준 충족 2개, 실제 생성 확인 보류 2개로 기록한다. 4개 모두 통과나
모델 정답률 50%라고 보고하지 않는다. 이번 실행에서 운영 코드는 변경하지 않았다.
