## 대기 지연과 판단

요청 구간 대기 호출은 535개, 평균 경과 78.30ms·최대 746.58ms다. 응답 완료로 끝난 3개 호출은 초과 대기 통계에서 제외했다. 나머지 532개의 요청 timeout 대비 추가 경과는 평균 18.76ms·p95 51.50ms·최대 730.54ms다. 의도한 대기 전체를 불필요한 지연으로 보지 않는다.

부모 표 통합 뒤 범위 검사 평균 경과가 줄어든 관찰은 있지만, 범위 검사 내부 지연과 OS 대기 지연이 모두 남는다. 현재 계측만으로 부모 표 취득·트리 구성·생성 시각 재확인·콘솔 호스트 확인 중 어떤 부분이 지배적인지, 경과/CPU 차이의 원인이 무엇인지 확정할 수 없다.
