# 새 질문 12개 경계 평가

평가일: 2026-10-07. 운영 코드 기준: `56b1841`.

## 조건과 범위

실행 전에 `edge_holdout_cases.json`에 새로운 질문 12개와 기대 항목을 작성했다.
실행 후 질문·검사 기준·운영 코드·Wiki를 수정하지 않았다.
운영 코드와 Wiki 및 문항 파일의 SHA-256을 실행 전후 확인해 변경이 없음을 기록했다.

- 실제 Wiki 검색 6문항: BM25, top-k 3, 기존 보충 검색 설정 유지
- 통제 근거 6문항: 가상의 역할·메모리 표를 메모리에서 전달, 검색 평가와 분리
- 실제 생성이 필요한 2문항만 qwen3:1.7b로 추가 실행
- 구현을 아는 내부 평가다. 외부 독립 평가나 대표 표본 정확도로 해석하지 않는다.
- 자동 검사는 문자열·출처·상태 확인이다. 질문 전체 의미의 정확성과 구분한다.

## 우선순위

1. 역할 표현·대상 개수와 무관하게 메모리 등 추가 요구의 누락을 잡는 공통 검사.
   단일 대상과 미지원 역할 의역이 기존 다중 대상 보호 경로를 우회한다.
   수치 검사 통과가 질문 전체 해결로 보이지 않도록 상태 표시도 구분할 필요가 있다.
2. 비교표와 일반 목록 사이의 명시적 역할 충돌을 확인하거나 지원 한계를 명확히 표시.
3. 도구 열 위치와 KiB 등 메모리 단위 인식 범위 확대.
4. 평가기는 정확한 출처를 가진 동등한 역할 표현을 별도 검토하도록 설계.
   이번 최초 결과의 기대 문자열을 사후 수정해서 통과 수를 올리지는 않는다.

이번 작업은 평가와 기록만 수행했다. 위 운영 개선은 아직 구현하지 않았다.
이 질문들을 개선에 사용하면 이후에는 개발 회귀 세트로 분류해야 한다.
