## 대기 및 다음 후보

대기 호출 247개는 평균 93.91ms·최대 1,569.14ms다. 완료로 끝난 2개 호출을 제외한 245개의 요청 timeout 대비 추가 경과는 평균 39.49ms·p95 125.92ms·최대 1,567.11ms다. 의도한 대기 전체를 불필요한 지연으로 해석하지 않는다.

이번 실행에서 확인된 주된 내부 지연 위치는 `parent_snapshot`이다. 이 단계는 ctypes API 준비·Windows 스냅샷 생성·전체 목록 열거·핸들 종료를 모두 포함하므로 어느 하위 호출이 지배적인지까지 확인된 것은 아니다. 다음 후보는 ON에서 이 네 묶음의 경과를 분리하는 것이다. 항목마다 기록을 추가하는 대신 열거 전체를 한 묶음으로 측정해 기록량을 제한한다. 이 추가 계측은 아직 구현하지 않았다.

부모 표를 표본 사이에 캐시하거나 안전 검사 빈도를 낮추는 개선은 하지 않는다. 기본 OFF를 유지하고 실제 개선 효과는 동일 소스 OFF/ON 및 반복 측정의 조건과 함께 판단한다. 정밀 순간 최대 RSS 보장은 계속 보류한다.
