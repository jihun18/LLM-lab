## 새 질문에서 드러난 문제와 수정

교정 12문항 및 기존 24문항과 다른 표현의 새 평가 질문 12개를 먼저 작성했다.
지원정책의 다른 연도, 실험하지 않은 모델, 다른 사람의 PC처럼 근접하지만 답이 없는
질문을 포함했다. 첫 실행 후 실패 분석과 수정에 활용했으므로 이제 이 세트는 개발
회귀 세트이지 독립적인 최종 테스트가 아니다.

- 질문은 2028년인데 2026년 지급액·마감일을 답하고 수치 검증 통과를 표시함.
- qwen3:32b를 요청했는데 qwen3라는 토큰이 겹친 4B 행을 표 추출기가 대신 선택함.
- 검증은 '원문에 숫자가 존재함'을 확인했을 뿐 '질문의 대상에 맞는 숫자임'을 확인하지 못함.

수정: 질문에 명시된 `20xx` 연도와 `모델명:크기b[-변형]` 태그가 검색된 **본문**에
있는지 먼저 확인한다. 없으면 생성 전 거절한다. 파일명만 일치하는 경우는 인정하지
않는다. 표 추출기는 모델 전체 태그가 맞는 행만 사용한다. 한국어 조사로 끝난 태그도
인식한다. 이 검사는 앱 공용 서비스 및 검색 평가에서 사용한다.

한계: 조건 문자열이 존재해도 해당 질문의 사실을 뒷받침한다는 보장은 없다. 동일 모델의
서로 다른 실험, 다른 인물, 관계·부정 표현·별칭·가정 질문 등은 추가 검증이 필요하다.
연도나 태그가 본문에 없는 가정·비교 질문은 보수적으로 거절될 수 있다. 완전한 의미 검증이 아니다.
